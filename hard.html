2. Ba lớp dữ liệu

Hardcode
Viết chết trong .vue

Chữ, icon, key, URL, fallback. Ví dụ tab “Thông tin nổi bật”, Math.trunc(1000000), ảnh OG Samsung.

CMS
Dynamic config / JSON

Chỉnh được không cần deploy. Fetch dynamic_config(key) hoặc cps_json(code). Banner KV, TNC, tabs upsell, theme.

API
Runtime theo user / SKU

Catalog, giá, tồn, thu cũ, review, FAQ, cart. Ví dụ products(), item-selection, calculateTradeIn.

CMS không phải hardcode, nhưng tên key (new_info_iphone_2026, …) vẫn hardcode trong code.
